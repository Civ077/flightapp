# ✈ 機票查價 PWA（手機版 v2.0）

自用機票比價 App：只看航空公司官網可售價、一鍵跳官網、緊急搶票、收藏航線看漲跌。
資料只存在手機；查價經由 Google Apps Script 中繼呼叫免費額度的航班資料 API；電腦版接頭已預留。

```
flightapp/
├─ index.html          手機介面（四個分頁：查價／緊急／收藏／設定）
├─ styles.css          舒適配色、深色模式、單手操作
├─ app.js              全部邏輯（防呆、排序、警示、收藏、設定、匯出入）
├─ i18n.js             介面文字：繁體中文／English（右上角一鍵切換，或設定→顯示）
├─ icons/              PNG 圖示（iOS 加入主畫面必須是 PNG）
├─ sw.js / manifest.json   PWA（加入主畫面、離線開啟）
├─ data/airports.js    128 座機場：IATA、繁中、英文、城市、國家、周邊群組
├─ data/airlines.js    57 家航空公司：代碼、繁中、英文、廉航/傳統、官網、航班動態
├─ data/holidays.js    台灣國定假日 2026–2027（日期旁 🎌 標示，可自行增修）
├─ backend/Code.gs     GAS 中繼：密碼、額度輪替、來源正規化、訂票管道
└─ desktop/server_stub.py  電腦版接頭骨架（FastAPI），之後接 fast-flights
```

## 一、部署步驟（說明）

### 1. 申請免費資料來源
| 來源 | 免費額度 | 申請 |
|---|---|---|
| SerpApi（主力） | 250 次／月 | serpapi.com 註冊 → Dashboard 取得 API Key |
| HasData（備援） | 約 67 次／月 | hasdata.com 註冊 → API Key |

### 2. 建立 GAS 中繼
1. 開 script.google.com → 新專案 → 貼上 `backend/Code.gs`
2. 專案設定 → 指令碼屬性，新增：
   - `APP_TOKEN`：自訂一組密碼（手機端要填同一組）
   - `SERPAPI_KEY`、`HASDATA_KEY`
   - （之後）`HOMEPC_URL`、`HOMEPC_TOKEN`
3. 編輯器執行 `TEST_search` 一次，授權並確認有回傳資料
4. 部署 → 新增部署作業 → 網頁應用程式 → 執行身分「我」、存取權「所有人」→ 複製網址（…/exec）

### 3. 放上手機
- 把 `flightapp/` 整個資料夾上傳到 GitHub Pages（或任何 https 靜態空間）
- 手機開啟網址 → 設定 → 連線：填「後端網址」與「密碼」→ 測試連線
- iPhone：Safari 分享 → **加入主畫面**（必要，否則 Safari 會定期清掉本機資料）
- Android：Chrome 選單 → 安裝應用程式

## 二之零、v2.0 新增功能

**結果頁**
- **前後 3 天比價**：按一下查前後各 3 天（最多 6 次額度，有快取不扣，執行前會先確認），顯示 7 格日期條，最便宜標綠、假日標紅，點日期直接切換
- **加查周邊機場**：桃園＋松山、成田＋羽田等同城機場一次查（1 次額度）
- **篩選列**：時段（早／午／晚／深夜）、直飛／≤1 轉、航空公司勾選，全部在手機端完成，不耗額度；顯示被篩掉筆數
- **含託運行李／選位的估算總價**：依設定頁費用表加總，廉航未填費用會標示；排序以估算總價為準
- **價格分布小圖**：依出發時間排列的價格長條，最低價標綠
- **低於行情**標記（Google 典型價格帶下限以下）
- **報到時間警示**：距起飛不到 3 小時或已起飛

**訂票面板**：加入行事曆（.ics，每段航班＋起飛前 3 小時提醒）、分享航班文字

**人數**：常用組合（例如「全家」）一鍵套用，長按移除

**設定**：行李／選位費用表（每人每航段）

**緊急頁**：台灣機場即時航班（TDX，免費）——出境／入境、依班號或機場篩選，取消紅字、延誤黃字、顯示登機門與航廈，每 2 分鐘更新

## 二、功能一覽（v1.1）

**查價**　來回票（兩步驟：選去程→看回程）／拆票（去回各查一次、顯示合計並可比較來回票）／單程、機場選擇（中文／英文／代碼搜尋，常用機場置頂）、日期防呆（不可早於今天、回程不可早於去程、不可超出開賣範圍）、人數票種（嬰兒 ≤ 成人）、艙等、只看直飛、最長總時程、只看指定航空公司。
**結果**　重新查價 ↻、30 分鐘內相同條件用本機與伺服器快取不扣額度、三個頁籤：最便宜／最推薦（可調權重）／最早抵達。每筆顯示價格與行情等級（低／中／高，同時標文字）、航空公司中文名、班號、起降時間（跨日 +1）、機場中英文全名、轉機資訊。
**警示**　短轉機、過夜轉機、長時間轉機、需換機場、多家航空公司需分開訂、紅眼班、經美加需過境文件。
**行情**　Google 的航線典型價格區間與目前水位。
**官網訂票**　一鍵複製航班資訊、各航空公司官網連結、Google 顯示的訂票管道（確認官網有售）。
**緊急**　目前位置→目的地，從現在起找最早抵達，可一併搜周邊機場（一次查詢）；颱風警報、機場即時航班、國籍航空異常公告連結。
**收藏**　記住完整條件，一鍵帶入；↻ 全部重查；顯示上次價格與漲跌；刪除可復原；日期已過會標示。
**設定**　航空公司勾選／排除／快選（全部、國籍、廉航）、常用機場、預設條件、警示門檻、主題與字體、匯出／匯入、本月剩餘額度。

## 三、資料準確度（重要）

- **價格來源**：SerpApi／HasData 都是即時讀取 Google Flights，同一時間四家服務回傳的最低價一致，等同你在 Google Flights 看到的價格。
- **官網價 ≠ 永遠相同**：Google 顯示的是航空公司回報給 Google 的票價，到官網時可能因為匯率、促銷代碼、會員價、剩餘座位變動而有小幅差異，所以 App 每筆都標示查價時間，並在跳轉前提醒「以官網為準」。
- **轉機與時間**：航班時刻、轉機時間、機場代碼來自航空公司班表，準確度高；時間一律為當地時間。
- **行情區間**：是 Google 依歷史資料算出的典型價格帶，供判斷「現在貴不貴」，不是保證。
- **行李、選位費用**：目前不含，第 3 版加入可自行維護的費用表。
- **額度**：免費額度用完時中繼會自動換下一家；都用完就會顯示錯誤，設定頁可看剩餘次數。

## 四、電腦版接頭（已預留）

手機 App 的每次請求順序：**家中電腦 → GAS 雲端**。只要在設定填入家中電腦網址，手機會先試連 4 秒，沒回應才改走雲端，使用上無感。

電腦版需提供三支 GET（與 GAS 相同參數與回傳格式，見 `backend/Code.gs` 檔頭與 `desktop/server_stub.py`）：
`/ping`、`/search?q=…`、`/booking?q=…&bt=…`。
對外可用 Tailscale Funnel 或 Cloudflare Tunnel 取得 https 網址。接上 fast-flights 後，查價即零成本、無次數上限；背景監控、整月矩陣、統計分析都放電腦版。

## 四之一、疑難排解

| 畫面訊息 | 原因 | 處理 |
|---|---|---|
| 密碼錯誤 | 手機密碼與 GAS `APP_TOKEN` 不同 | 兩邊貼同一組，注意前後空白 |
| 後端回應不是 JSON | 網址不是 …/exec，或部署存取權不是「所有人」 | 重新複製部署網址；檢查存取權 |
| GAS 尚未設定 APP_TOKEN | 指令碼屬性沒存到 | 重新新增屬性並儲存 |
| SerpApi 金鑰無效 | 金鑰貼錯或帳戶未驗證 Email | 到 SerpApi Dashboard 重新複製 |
| 沒有可用的資料來源 | 本月額度用完 | 等下月，或改用家中電腦 |
| 連線逾時 | Google 回應慢，超過 GAS 60 秒 | 再按一次；若常發生，確認 `DEEP_SEARCH` 未開 |
| serpapi: Google hasn't returned any results | 該航線該日無航班或條件太嚴 | 放寬條件、改日期 |
| 此來源未提供回程選項 | 來源不是 SerpApi | 改用「拆票」模式 |
| GAS 尚未設定 TDX 金鑰 | 未填 TDX 屬性 | 依檢核表第 11 步申請（免費），或先用連結查機場網站 |
| TDX 取得 token 失敗 | Client Id／Secret 貼錯 | 到 TDX 會員中心重新複製 |
